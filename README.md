# Team Git Practice

这是本组 Git 与 GitHub 协作练习仓库。

## 练习目标

每位成员独立完成一次以下流程：

1. Clone 本仓库到本地
2. 从 `main` 创建自己的练习分支
3. 在“成员提交区”增加一行个人信息
4. Stage 并 Commit
5. Push 到 GitHub
6. 创建 Pull Request
7. 等待队长审核并合并

## 统一规则

* 不允许直接修改 `main`
* 每个人只修改自己的一行
* 每个人必须创建自己的分支
* 不要删除或修改其他成员内容
* 遇到报错先截图，不要反复乱点

## 分支命名格式

```text
practice-昵称
```

示例：

```text
practice-qiaoyu
practice-lldy
```

## Commit 信息格式

```text
[practice] 添加昵称个人信息
```

示例：

```text
[practice] 添加乔宇个人信息
```

## Pull Request 标题格式

```text
[practice] 昵称完成 Git 提交练习
```

示例：

```text
[practice] 乔宇完成 Git 提交练习
```
